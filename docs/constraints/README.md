# Constraints

Standing constraints that are not a single ADR live here as `docs/constraints/<slug>.md` (compliance, data residency, vendor limits). Link the related ADR or intent. A new file stays `Status: draft`, lists open questions, and gives every check an enforcement point. Only a human sets `accepted`.

Product non-goals stay in `docs/product-brief.md`. Decisions stay in `docs/adr/`.
