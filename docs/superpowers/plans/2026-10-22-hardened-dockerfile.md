# Hardened Production Container Image Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Lifecycle: DRAFT (AI-drafted at the owner's request. Only a human sets `accepted` or `APPROVED`.)

**Goal:** Ship a minimal, non-root, read-only-compatible OTP release image. The build context must leave out every developer and AI-assistant file (skills, rules, `*.md`, docs, intents, evals, tests).

**Architecture:** A multi-stage `Dockerfile`. The builder stage is `hexpm/elixir` on Debian bookworm-slim. It compiles deps, builds assets, and runs `mix release`. The runtime stage is bare `debian:bookworm-slim` and holds only the release plus the shared libraries ERTS needs. A deny-by-default `.dockerignore` allowlists only what the build needs. `scripts/docker-verify.sh` holds the automated proof, and CI runs it.

**Tech Stack:** Docker BuildKit (`# syntax=docker/dockerfile:1`), Elixir 1.20 / OTP 27 (matches `.github/workflows/ci.yml`), Phoenix 1.8 release tooling (`mix phx.gen.release`), hadolint, Trivy.

## Global Constraints

- Builder Elixir/OTP = CI: Elixir `1.20.x`, OTP `27.x`. The builder and runtime use the same Debian release (`bookworm`).
- Pin every base image by **digest** (`image:tag@sha256:…`). Resolve digests at implementation time with `docker buildx imagetools inspect <image:tag>`. Never invent a digest.
- Runtime user: numeric UID/GID `10001:10001`, no login shell, no home directory writes.
- Runtime image contains **no** compiler, `git`, `curl`, `wget`, `mix`, `hex`, or package-manager caches.
- No secret is passed as an `ARG` or `ENV`, or written into any layer. All secrets come from runtime env (`config/runtime.exs`).
- Build context excludes: `AGENTS.md`, `GEMINI.md`, `README.md`, `CHANGELOG.md`, every `*.md`, `.agents/`, `.cursor/`, `.github/`, `.githooks/`, `docs/`, `intent/`, `evals/`, `quality/`, `scripts/`, `test/`, `deps/`, `_build/`, `tmp/`, `.elixir_ls/`, `.env*`, `erl_crash.dump`, `priv/plts/`, `priv/uploads/`, `priv/static/assets/`, `priv/static/cache_manifest.json`, `config/dev.exs`, `config/test.exs`.
- No `mix.exs` dep or `mix.lock` hand-edits (AGENTS.md). `mix phx.gen.release` adds no deps.
- Never push images or deploy (autonomy L2). CI builds and scans only.

## Review Focus

1. **Read-only root FS with the default `Storage.Local`.** `local_root: "priv/uploads"` is not writable. Expected behavior: the docs say production uses `STORAGE_BACKEND=s3` or mounts a volume. The verify script asserts `/app` is not writable by UID 10001 (Task 3).
2. **`RELEASE_COOKIE` unset.** The container must exit non-zero before boot, not start with a baked or empty cookie (Task 2 + Task 3 assertion).
3. **`SIGTERM` from orchestrator.** Graceful shutdown with exit code `0` within the stop timeout (Task 3 assertion).
4. **Arch mismatch** (arm64 Mac build vs amd64 prod). The argon2 NIF is compiled for the builder arch. CI builds `--platform linux/amd64` and asserts `.Architecture == "amd64"` (Task 4).
5. **Secrets in image history.** `docker history --no-trunc` must contain no `SECRET`/`TOKEN`/`PASSWORD`/`COOKIE` values in any `ENV`/`ARG` (Task 3 assertion).

### Task 3: Dockerfile, .dockerignore, verify script

**Files:**
- Create: `Dockerfile`, `.dockerignore`, `scripts/docker-verify.sh`

**Interfaces:**
- Consumes: Task 1 overlays and Task 2 `env.sh.eex`.
- Produces: an image whose `ENTRYPOINT`/`CMD` is `["/app/bin/server"]` and where `/app/bin/migrate` exists. `scripts/docker-verify.sh [IMAGE]` exits 0 only when every assertion passes (default image tag `phx_backend_boilerplate:verify`).

`.dockerignore`: start with `*`, then re-include only `mix.exs`, `mix.lock`, `config/`, `lib/`, `priv/`, `assets/`, `rel/`. Then re-exclude the Global Constraints paths that sit under those dirs, plus `**/*.md`.

Dockerfile decisions:

| Concern | Decision |
| --- | --- |
| Stages | `deps` (hex/git fetch) → `build` (compile, `mix assets.deploy`, `mix release`) → `runtime` |
| Builder pkgs | `build-essential git ca-certificates`, `--no-install-recommends` (git: heroicons/daisyui git deps; build-essential: argon2 NIF) |
| Dep fetch | `mix local.hex --force && mix local.rebar --force`, then `mix deps.get --only prod --check-locked` (confirm the flag exists in Elixir 1.20 before use) |
| Layer caching | Copy `mix.exs mix.lock` + `config/config.exs config/prod.exs config/redaction_keys.exs` before `lib/` and `assets/`. BuildKit `--mount=type=cache` for `/root/.hex`, `/root/.mix`, `/root/.cache` |
| Release tweaks | After `mix release`, `rm releases/COOKIE` in the release dir |
| Runtime pkgs | `libstdc++6 openssl libncurses6 ca-certificates` only, `rm -rf /var/lib/apt/lists/*` |
| Locale/env | `LANG=C.UTF-8`, `MIX_ENV=prod`, `RELEASE_TMP=/tmp`, `ERL_CRASH_DUMP=/tmp/erl_crash.dump`, `HOME=/tmp` |
| Ownership | Release copied `--chown=root:root --chmod=go-w`, so the app user cannot modify code |
| Hardening | Strip setuid/setgid bits (`find / -xdev -perm /6000 -type f -exec chmod a-s {} +`). User `10001` created with `/usr/sbin/nologin`. `USER 10001:10001` |
| Ports / signal | `EXPOSE 4000`. Default `STOPSIGNAL` (SIGTERM). No tini (ERTS reaps its own children) |
| HEALTHCHECK | None. No curl in the image; orchestrators use `/health` and `/ready` (README). Trivy DS026 is LOW, below the HIGH,CRITICAL threshold |
| Labels | OCI `org.opencontainers.image.{source,revision,created,licenses}` from `ARG`s with no secret content |
