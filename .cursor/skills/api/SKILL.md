---
name: api
description: Apply when adding or changing endpoints, commands, queries, events, or public contracts.
---
- State whether the surface is a command, a query, or an event. Name idempotency, versioning, and the error contract.
- Authenticate non-public endpoints and validate input at the boundary. See the security-baseline skill.
- A public contract change is tier 2 and needs an ADR before implementation.
